# GenPark Multi-Agent Borda Voting Consensus

## Description
Positional Borda Count voting and weighted multi-agent consensus engine resolving conflicting model proposals.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery, MCP.Directory
